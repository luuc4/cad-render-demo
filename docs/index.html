Aus dem CAD‑Modell wird ein Produktvideo

Drei nahtlose Loops aus derselben Datei: eine Drehung und zweimal der Zusammenbau. Ein Script rendert sie in Blender und macht daraus kleine Web-Videos, die auf einer weißen Seite ohne sichtbaren Rand stehen.

Zusammenbau: mit oder ohne Animation in der Datei

Für eine Drehung reicht jedes Modell. Für den Zusammenbau muss das Script wissen, welches Teil auf welchem Weg an seinen Platz fährt. Diese Wege kommen entweder aus der Datei oder werden aus der Form der Teile berechnet. Beide Videos laufen synchron, damit Sie den Unterschied direkt sehen.

Die Leiste unter jedem Video zeigt den Ablauf. Am Ende geht das Video ohne Schnitt in den Anfang über.

Animation aus der DateiAutomatisch berechnet
Woher die Wege kommen Aus der Explosionsansicht, die im CAD- oder 3D-Programm angelegt und als Animation mit exportiert wurde, zum Beispiel in einer FBX- oder glTF-Datei. Aus der Form jedes Teils: Schrauben und Bolzen fahren längs heraus, Deckel, Scheiben und Platten senkrecht zur Fläche, alles andere von der Mitte weg.
Reihenfolge Wie bei der echten Montage. Innere Teile zuerst, äußere zuletzt.
Genauigkeit Mechanisch korrekt, kein Teil fährt durch ein anderes. Plausibel. Auf dem Weg können sich Teile durchdringen, bei Innenteilen fällt das eher auf.
Ihr Aufwand Explosionsansicht einmal anlegen und als Animation mit exportieren. Keiner, die Datei muss nur aus einzelnen Teilen bestehen.

Welche Datei es braucht

  • Jedes Bauteil als eigenes Objekt. So wie es im CAD als Körper oder Komponente angelegt ist: Gehäuse, Deckel, jede Schraube einzeln.
  • Formate: FBX, glTF/GLB oder OBJ direkt. STEP wird vorher umgewandelt, zum Beispiel mit FreeCAD.
  • Maßstab egal. Ob Millimeter oder Meter, das Script korrigiert den Maßstab beim Import.
  • Für einen genauen Zusammenbau: die Explosionsansicht aus dem CAD als Animation in der Datei. Fehlt sie, berechnet das Script die Wege selbst.
  • Farben und Oberflächen geben Sie als Farbwerte vor, etwa Ihre Markenfarbe als Hex-Wert.

Keine verschmolzene STL-Datei

Eine STL speichert nur Oberflächen, keine Bauteile. Wird beim Export alles zu einem Körper vereinigt, gibt es keine Teile mehr, die sich bewegen könnten. Eine Drehung geht dann noch, ein Zusammenbau nicht.

Stecken die Teile in der STL noch als getrennte Hüllen, lassen sie sich wieder auseinandernehmen.

So kommt das Video auf die Website

  • Zwei Dateien pro Video: WebM (VP9) für Chrome, Firefox und Edge, MP4 (H.264) für alle anderen.
  • Der Hintergrund ist pixelgenau die Farbe Ihrer Seite, hier #FFFFFF. Die Farbe ist frei wählbar.
  • Diese Demo läuft in 960×540, damit sie schnell lädt. Für die Website geht auch 1920×1080.
  • Wer in den Systemeinstellungen „Bewegung reduzieren“ aktiviert hat, sieht nur das Standbild.
